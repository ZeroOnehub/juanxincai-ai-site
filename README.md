# 卷心菜 · AI 工坊

> 用 AI 帮你提升效率、降低成本、创造增长 —— 提供 AI 文案、Prompt 工程、自动化解决方案。

这是 AI 自由职业者「卷心菜」的个人网站：一个面向获客与个人品牌建设的中文单页站点。
它不只是介绍服务，而是直接放了一个**可以玩的 AI 工坊**，让访客现场看到 Prompt、文案、自动化流程是怎么被组织起来交付的。

🔗 线上地址：https://zeroonehub.github.io/juanxincai-ai-site/

## 网站亮点

**内容与交互**
- **首屏实时演示**：模拟"用户提需求 → AI 思考 → 输出结果"，自动轮播 3 个示例
- **AI 工坊**：文案生成、Prompt 优化、流程设计三个可玩小工具
- **合作流程**：四步交付时间线
- **案例展示**：可展开的"问题 → 方案 → 结果"卡片
- **关于我**：聊天气泡形式的常见问题问答
- **命令面板**：按 `/` 快速跳转到任意板块
- **一键复制邮箱**，方便直接联系

**炫酷特效层**（`fx.css` + `fx.js`）
- 会跟随鼠标的粒子神经网络背景 + 缓慢漂移的极光光斑
- 首屏透视网格地面、流光渐变标题
- 演示窗旋转流光边框、扫描线、鼠标 3D 倾斜
- 卡片鼠标聚光边框、标题乱码解码动画
- 技能关键词跑马灯、按钮光泽扫过、点击火花

特效会自动照顾体验：切到后台时暂停动画；系统开启"减少动态效果"时自动关闭；手机上不启用鼠标类特效。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构 |
| `styles.css` | 基础视觉样式与响应式布局 |
| `script.js` | 内容数据（顶部 `SITE` 对象）与主要交互 |
| `fx.css` / `fx.js` | 炫酷特效层，删掉这两个文件即回到简洁版 |
| `DESIGN.md` | 视觉设计规范 |
| `.cursor/rules/project-context.mdc` | 项目长期上下文 |
| `.prompt` | 后续构建执行提示词 |

## 怎么修改内容

- 个人信息、统计数字、演示示例、案例、问答：改 `script.js` 顶部的 `SITE` 对象
- 跑马灯里的技能关键词：改 `fx.js` 顶部的 `MARQUEE_WORDS`
- 本地预览：直接双击打开 `index.html` 即可

## 发布
